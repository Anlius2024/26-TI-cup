## 题目

设计并制作电路网络特性测量装置，包括信号发生部分和信号检测部分，如图 1 所示。该装置能适应对被测网络测量时，信号发生和信号检测部分不在一处的情况。信号发生和信号检测部分通过可见光进行通信。装置可自动产生所需测量信号，完成对被测网络（下限截止频率不小于 200 Hz，上限截止频率不大于 2 kHz）的频率特性和冲激响应的测量。

```
    |--▶ 可见光通信  ⭕
    |   (5–10 mm)   |
    |               |
    |               |
信号发生 ➡ 被测网络 ➡ 信号检测
```

## 要求

1. 装置的信号发生部分能产生正弦信号，频率 10 Hz–20 kHz 可设置、步长 10 Hz，输出电压峰峰值 1 V–3 V 可设置、步长 0.1 V，相对误差绝对值均不大于 5%。

2. 装置的信号发生和信号检测两部分可通过可见光进行通信。不接入被测网络，信号发生部分随机设置其输出正弦信号的频率和峰峰值，信号检测部分可以文字显示信号发生部分信号的频率和峰峰值；当信号发生部分产生的正弦信号频率为 19 kHz–20 kHz 时，通过模拟信号可见光通信。信号检测部分还能输出与信号发生部分同频率的正弦信号，要求信号波形无明显失真，峰峰值不小于 3 V。

3. 接入被测网络，信号发生部分正弦信号的峰峰值随机设置后固定不变、频率自动变化，装置能测量被测网络的频率特性：在信号检测部分定量显示被测网络的幅频和相频曲线（频率范围 10 Hz~20 kHz），并用文字标出下限截止频率和上限截止频率 10 倍处的坐标值，相对误差绝对值不大于 10%。

4. 接入被测网络，信号发生部分输出信号不做限制，装置能定性测量被测网络的冲激响应；在信号检测部分定性显示被测网络的冲激响应曲线（时间范围为 0–2 ms），并文字显示冲激响应曲线上非 0 时刻极值点的数量。

5. 其他。

## 说明

1. 信号发生和信号检测两部分相互独立，两者仅通过可见光进行通信，预留其输出测试端口。

2. 参数设置等在信号发生部分，信号检测部分无按键，上电后自动工作。每项测试时，参数设置完成后，测量时间均不大于 1 分钟。

3. 可见光通信采用常用的光电器件，光源为白色 LED，光敏器件为光敏二极管或光敏三极管。光源和光敏器件需外露可见，两者距离自选定后固定不变。不可采取额外的光源聚光等措施。

4. 要求 2 观测信号检测部分输出的正弦信号，示波器以信号发生部分输出为触发通道，要求双踪显示的信号检测部分与信号发生部分输出波形无漂移，无抖动。

5. 测频现场提供被测网络，由 RLC 元件组成，其输入电阻不小于 2 kΩ。

6. 要求 3、4 的坐标标示：频率特性的横坐标 kHz，保留两位小数；幅频纵坐标 dB，相频纵坐标度，均保留一位小数。冲激响应的横坐标 ms，纵坐标无单位（数据归一化，最大响应值定义为 1）。

## 题目要点拆解

题目的核心难点在于**信号发生与信号检测物理分离，二者之间只有一条可见光信道**（白色 LED → 光敏二极管/三极管，距离 5–10 mm，固定不变，不允许聚光）。这带来三个工程约束：

| 约束 | 影响 |
|---|---|
| 检测端**无按键**、上电自动工作 | 全部人机交互与参数设置必须在发生端；检测端只能被动接收 |
| 两者**仅通过可见光通信** | 需要一个光通信协议：低频段传数字信息（频率/峰峰值），19–20 kHz 频段传模拟信号 |
| 要求 2 需**无漂移无抖动** | 检测端恢复出的正弦必须与发生端同频同相，对光信道的相位稳定性提出要求 |

测量部分则分解为两个独立任务：

- **频率特性**（幅频 + 相频，10 Hz–20 kHz）：需要扫频、测幅度比与相位差，并标出下限/上限截止频率及其 10 倍频点的坐标，误差 ≤ 10%
- **冲激响应**（0–2 ms）：需要定性获取并显示冲激响应曲线，统计非 0 时刻极值点个数

被测网络由 RLC 组成，输入电阻 ≥ 2 kΩ，截止频率落在 200 Hz–2 kHz —— 即测量带宽需要覆盖被测网络截止频率的约 10 倍以上两端。
